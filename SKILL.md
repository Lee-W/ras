# RAS — RAISE A SLIDE

Read [the router](skills/command-router/SKILL.md), then the matching operation
skill. For a natural-language request, choose the operation that matches the
user's intent. To discuss structure first, use `outline`. Without that request,
a new topic or a plan-only outline uses `create`.

This entry supports a whole-repository installation in `.agents/skills/ras/`.
Keep supporting files beside it; scripts and references use relative paths.
