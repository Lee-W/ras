# Wei's presentation profile

Observed in the supplied reference decks; use as a
starting profile rather than assuming every talk needs the same treatment.

- Short sentences and large type; one conceptual beat per slide.
- Build concepts across successive pages. Keep deliberate setup, repetition,
  silence, callbacks, and punchlines instead of condensing them into bullet lists.
- Dark backgrounds, condensed display type, selective gold/cyan emphasis.
  Conference and employer branding are optional, project-specific choices.
- Use code, ASCII/Mermaid diagrams, screenshots, and occasional relevant memes.
  Preserve credits and provenance; memes are not mandatory decoration.
- A technical audience and a general audience need different introductions.
  Define unfamiliar terms at first use. Bio placement depends on the room.
- Slide language can be English while speaking language is Taiwanese Mandarin.
- Technical claims should have versioned sources. Keep performance directions
  in notes and research/editorial history in separate project documents.
- Thirty-minute examples contain over a hundred pages, many with only one line.
  Assess pacing by what is spoken and demonstrated, not page count.
