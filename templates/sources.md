# Sources and assets

The starter talk is an original presentation exercise. Its code is illustrative
pseudocode, and its timing is a rehearsal target.

For a real talk, record each consequential claim with its source URL or local
document, relevant version/date, and the slide heading. Record artwork provenance
and credits here too. Preserve research detail separately from speaker notes.

## Image rights ledger

Follow [image rights and credits](image-rights-guide.md). Include every supplied
or selected image, screenshot, logo, CSS background, and embedded image; group
repeat uses by asset ID and list all slide headings/pages. The starter contains
only an original Mermaid diagram and no third-party image assets. Its original
diagram is covered by `RAS-LICENSE`; the dependency font notices below still apply.

For each added asset, copy and fill these fields with real evidence:

- Asset ID / local path / slide headings and latest page numbers:
- Source page or supplied document / creator / rights holder if identified:
- Intended use (live, recorded, public HTML/PDF, source sharing, commercial):
- Use basis / licence and version or permission / restrictions:
- Evidence checked / date / reviewer:
- Credit decision (`required`, `not-required`, `unknown`) and reason:
- Exact required text, notices, links and change indications:
- Changes to the image / credit placement in HTML and PDF:
- Outcome (`verified`, `pending`, `replace`) / unresolved action:

User-provided does not mean permission verified. Do not invent a rights holder
or mark unknown rights as cleared. Required audience credits belong on slides;
this ledger and speaker notes do not replace them.

## Dependency fonts

The build copies Roboto, Roboto Condensed, and Roboto Mono from their pinned
Fontsource packages, plus Noto Sans TC Variable for Taiwanese Mandarin written
in traditional characters.
Font licences are included in `dist/assets/fonts/`. Mermaid SVGs embed the font
subsets needed for their labels and retain the same notices in the output tree.
