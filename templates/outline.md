# Outline: Give one idea a stage

One section per slide, in talk order. Refer to slides by heading; page numbers
shift when slides are added or split. LAYER owns this file. PAREO decides each
`layout` value (a theme class such as `title`, `statement`, `section`, `compare`,
`code`, `image`, or `closing`) and LAYER records it here; leave it `TBD` until
then. Image entries and claims listed under `sources to add` become entries in
`sources.md`.

Replace the two example slides below with the actual talk.

## Give one idea a stage.

- purpose: Name the talk and invite the audience to recall one presentation they remembered.
- time budget: 20 seconds
- layout: title
- visual opportunity: Title only; let the question carry the opening.
- sources to add: none

## What should they remember?

- purpose: Ask the question that defines the talk's purpose before any advice.
- time budget: 30 seconds, including a pause
- layout: statement
- visual opportunity: One sentence, large type, nothing competing with it.
- sources to add: none; the question is the speaker's own framing
