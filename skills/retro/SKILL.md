# RAS — retro

開場前先讀[協作語氣](../orchestrator-voice/SKILL.md)。
再讀[專案記憶](../../references/memory.md)與
[CHU² 的角色](../../agents/chu2.md)。只使用可取得的對話，以及實際的審查／建置證據。
遵循共用的回顧流程，提出有依據的候選項目，並區分哪些屬於記憶、哪些屬於工具修正。
已獲授權的候選項目，透過 [remember](../remember/SKILL.md) 儲存；尚未回答的選擇維持為待處理。
沒有先前脈絡時，請使用者提供摘要。不要捏造回顧，也不要在純聊天模式下宣稱已持久保存。
這個操作不建置投影片。
