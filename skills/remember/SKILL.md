# RAS — remember

開場前先讀[協作語氣](../orchestrator-voice/SKILL.md)。
再讀[專案記憶](../../references/memory.md)與
[CHU² 的角色](../../agents/chu2.md)。確認目標專案與既有的條目，再遵循共用的 remember 寫入規則。
保留使用者的原意與既有的授權。回報實際儲存的文字、ID 與本機路徑。
只有純聊天權限時，提供建議的條目與儲存方式；不要宣稱已經跨 session 記住。
這個操作不建置投影片。
