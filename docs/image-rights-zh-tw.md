# 圖片權利與標示

[English](../references/image-rights.md) · [臺灣華語](image-rights-zh-tw.md)

簡報完成前，要逐一查核提供或選用的圖片。使用者提供、網路上看得到，或已經附上出處，
都不代表符合這次使用情境的授權；使用依據與署名要求分別確認。

## 盤點與證據

由 PAREO 盤點、MASKING 複核證據與最終標示。
範圍包含 Markdown 圖片、CSS 背景、HTML 圖片、截圖、標誌、迷因、舊簡報圖片與圖表內嵌圖片。
重複使用的素材可共用一筆 `sources.md` 紀錄，列出所有投影片標題及最新頁碼。

每筆素材記錄：

- 本機路徑、原始來源頁或提供的文件、已確認的創作者與權利人，以及證據和查核日期。
  優先查原作者、出版者、權利人或原始儲存庫的條款，不以搜尋結果或轉貼取代。
  不從外觀猜測權利人，也不捏造版權文字。
- 預定用途：現場演講、錄影、公開 HTML／PDF、提供原始檔，以及是否涉及商業使用。
  缺漏若會影響判斷，再向使用者確認；一種用途的許可不一定涵蓋其他用途。
- 使用依據：授權名稱與版本、書面許可、自有原創、公眾領域依據或其他主張的依據。
  記錄改作、再散布、非商業或相同方式分享等適用條件。
  主張法律例外時，要記錄與情境相關的依據，不能只因教育用途或迷因就判定可用。
- 標示判定：`required`、`not-required` 或 `unknown`，附理由，以及必須保留的姓名、聲明、
  連結與修改說明；條款若區分署名對象與著作權人，紀錄也要區分。
- 投影片實際標示文字與位置，或不需標示的證據；依情況記錄裁切、註記、翻譯等修改。
- 結果：`verified`、`pending` 或 `replace`，以及待辦事項。
  `verified` 表示所記錄的證據支持指定用途與條件，是審閱結論，不是法律保證。

使用者自有原創可能不需要第三方標示，記錄依據即可，不加上虛構權利人。
AI 生成圖片仍記錄工具、適用條款、參考素材及未解決的第三方權利，不自動視為無版權。
截圖與標誌也要查核其中內容及適用條款，不能只確認截圖者。

## 投影片上的標示

需要標示時，原則上以 `.credit` 放在使用圖片的投影片；實際條款允許時，
也可放在能清楚對應素材的出處頁。保留指定文字、連結與聲明，不能假設自行寫的 `© 權利人` 就足夠。
例如 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)要求署名、授權連結及修改說明，
並須保留適用的既有聲明；不同 Creative Commons 授權仍應分別閱讀。

`sources.md` 保存查核證據，不能取代觀眾應看得到的標示。
講者備註與 HTML 註解不會出現在觀眾版 PDF；實際檢查最終 HTML 與 PDF，
確認標示清楚、沒有裁切、聲明保留且必要連結有效。
保留既有浮水印與署名；裁切若會移除它們，先確認許可，再調整裁切或選用其他素材。

## 缺少證據與審閱

無法瀏覽或取得條款時，請使用者提供來源、授權或許可證據，並標為 `pending`。
不能因建置通過或沒有版權符號就判定可用；可先以明確佔位內容或已查核的替代方案繼續草稿，
但不擅自替換使用者指定的圖片。

納入簡報的圖片若仍有未知使用權利，或缺少必要標示，不得宣稱 `READY`，也不得記錄通過的事實審閱。
缺證據使用 `UNVERIFIED`，已知使用衝突或漏標使用 `NEEDS_CHANGES`。
事實審閱的觀察欄記錄素材 ID、頁面範圍、證據與結論；視覺審閱確認標示位置與可讀性。

建立與修改時查核新增、變更的圖片，用途改變也要重查。
審閱涵蓋全部圖片；匯出確認先前相符的圖片權利審閱，或回報缺漏。
過去事實審閱若沒有圖片查核證據，不能直接沿用為完成依據。
草稿仍可匯出，但保留真實的 pending／needs-changes 狀態。
腳本只驗證審閱紀錄格式與有效性，不會自行判定圖片所有權或閱讀授權條款。

純聊天模式只根據實際提供的證據提出紀錄與標示草稿，不宣稱已瀏覽或檢查畫面，並列出待驗證事項。
