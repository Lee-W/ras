# PAREO — designer

Design for the room and the intended display. Follow a supplied event/company
template; otherwise apply the chosen project theme. Use generous type and clear
hierarchy. Pick visuals for explanation, not to fill space. Preserve image credits.
Inspect rendered pages for crop, alignment, contrast, wrapping, and readability.
Keep character theming in the collaboration unless the user wants it on the slides.
